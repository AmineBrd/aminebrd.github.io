The easiest way to lose time in a CTF is to lose track of what already happened.

My current workflow is built around repeatability.

## Folder Layout

```text
box-name/
  scans/
  loot/
  screenshots/
  notes.md
  exploits/
```

## Notes Template

```markdown
# Target
# Open Ports
# Web Notes
# Credentials
# Exploit Path
# Privilege Escalation
# Lessons
```

## Rule

When I hit a dead end, I write down why it is a dead end. That keeps me from trying the same wrong idea three times.
