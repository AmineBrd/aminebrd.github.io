## Goal

Build a safe environment where I can break things, capture logs, reset machines, and learn without touching systems I do not own.

## First Services

- Kali or Parrot attack VM.
- Ubuntu server target VM.
- Vulnerable web app container.
- Logging box for SSH, web, and auth logs.

## Next Step

Document each service as I deploy it, including the exact command that started it and how to tear it down.
